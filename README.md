# 🧠 Mental Health Risk Prediction System

## 📌 Overview
This project predicts mental health risk using machine learning based on workplace and personal factors.

---

## 🎯 Features
- Predicts Risk Level (Low / Medium / High)
- Confidence Score
- Personalized Recommendations
- Interactive Web App using Streamlit
- Dynamic Visualization Dashboard

---

## ⚙️ Technologies Used
- Python
- Scikit-learn
- Streamlit
- Pandas & NumPy

---

## 🧠 Feature Engineering
- Support Score = benefits + care_options
- Work-Life Balance = stress / support

---

## 🤖 Models Used
- Logistic Regression
- Random Forest
- XGBoost
- SVM (for comparison)

---

## 📊 Model Performance
- Accuracy: ~80%
- F1 Score: ~0.79–0.82

---

## 📊 Visualization
- Mental Health Factors Impact Chart
- Dynamic user-based predictions

---

## 💼 Business Insights
- High stress increases mental health risk  
- Lack of company support increases vulnerability  
- Family history is a major factor  

👉 Companies can improve employee wellness programs using these insights.

---

## ⚖️ Bias Detection
- Checked age distribution
